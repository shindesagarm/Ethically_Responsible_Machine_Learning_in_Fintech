This is a project work done as a part of MS program in Machine Learning and AI, July 2024 provided by
Liverpool John Moores University, UK.

**Author**: Sagar Shinde

Ethical principle similarity was computed using a Sentence-BERT–based embedding approach (implemented separately for reproducibility using the ‘all-MiniLM-L6-v2’ transformer model), followed by cosine similarity analysis to identify alignment among OECD, EU, and IEEE principles.
